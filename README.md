💡 Why I built FinSight AI — and the real problem it solves
Every quarter, banks like BNY Mellon file hundreds of pages of financial reports with the SEC.
Fund managers. Analysts. Investors. They all have to manually read through these massive documents just to find key insights, risks and financial numbers.
That takes hours. Sometimes days.
There had to be a better way.
So I built FinSight AI — a pipeline that automates this entire process.
It fetches the filing directly from SEC EDGAR, processes it through a data pipeline, and delivers a structured AI-generated analysis in under 30 seconds.
✅ Sentiment score — Bullish or Bearish?
✅ Risk flags — what are the red alerts?
✅ Key insights — what actually matters?
✅ Financial metrics — revenue, EPS, ROE extracted automatically
The real world impact:
📌 Investment analysts can screen 10x more companies in the same time
📌 Risk teams get instant red flags without reading 200 pages
📌 Portfolio managers get a signal before deep diving
📌 Retail investors can finally understand complex filings in plain English
Built this as a 3rd year Engineering student using PySpark · DuckDB · Groq (Llama 3) · SEC EDGAR · Streamlit
